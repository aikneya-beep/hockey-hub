# Мой хоккей — MVP 0.2

Личный веб-агрегатор пяти команд:

- СКА — КХЛ
- СКА-ВМФ — ВХЛ
- СКА-1946 — МХЛ
- Академия СКА — МХЛ
- Эскулап — СПбХЛ

## Что уже есть

- единая SQLite-база матчей;
- upsert по `source + source_game_id`;
- адаптер KHL/MHL internal API;
- HTML-адаптер официального сайта СКА-ВМФ;
- HTML-адаптер Эскулапа в СПбХЛ;
- единая веб-лента и состояние источников;
- параллельное обновление источников;
- автоматическое обновление при старте и каждые 30 минут, пока сервер работает;
- PWA-манифест и service worker — сайт можно добавить на домашний экран телефона;
- `render.yaml` для развёртывания на Render.

> KHL/MHL API — внутренний API приложений, не официальный публичный API. Адаптер изолирован на случай изменений.

## Локальный запуск

Нужен Python 3.11+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Windows PowerShell:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Открыть `http://127.0.0.1:8000`.

## Развёртывание на Render

1. Создать GitHub-репозиторий и загрузить в него содержимое этой папки.
2. В Render выбрать **New → Blueprint** (либо Web Service) и подключить репозиторий.
3. Render увидит `render.yaml`; подтвердить создание сервиса.
4. После деплоя появится публичный адрес вида `https://hockey-hub-ska.onrender.com`.

На бесплатном Render файловая система временная: SQLite может очищаться при перезапуске/засыпании. Для этого MVP это допустимо — при старте база создаётся заново, получает встроенный стартовый снимок и сразу запускает обновление всех источников.
